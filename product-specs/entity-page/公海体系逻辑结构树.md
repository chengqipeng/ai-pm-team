## 一、实体结构树

```
CRM 业务实体
│
├── 公海池配置（池级别，管理后台维护）
│   │
│   ├── highSea（客户公海池）
│   │   ├── [固定列] id / name / ownerId / departApiKey / tenantId
│   │   ├── [业务字段]
│   │   │   ├── assignRule          领取规则（0=自行领取 1=手动分配）
│   │   │   ├── recycleRule         回收规则（0=自动 1=手动）
│   │   │   ├── transferRule        转移规则（0=仅管理员 1=成员可转）
│   │   │   ├── noActivitiesDay     无跟进回收天数
│   │   │   ├── noNewOppDay         无新商机回收天数
│   │   │   ├── noTransferDay       无成交回收天数
│   │   │   ├── remindDay           提前提醒天数
│   │   │   ├── claimLimitDay       回收后禁领天数
│   │   │   ├── releaseLimit        退回次数限制
│   │   │   ├── claimMaxCount       每人最大持有数
│   │   │   ├── enableFlg           是否启用
│   │   │   └── description         描述
│   │   │
│   │   ├── ◆ highSeaMember（子实体：公海池成员）
│   │   │   ├── highSeaId           → highSea.id
│   │   │   ├── userId              → user.id
│   │   │   ├── memberRole          0=成员 1=管理员 2=默认管理员
│   │   │   └── memberStatus        1=启用 0=停用
│   │   │
│   │   └── ◆ highSeaDepart（子实体：公海池部门范围）
│   │       ├── highSeaId           → highSea.id
│   │       ├── departApiKey        部门 apiKey（String，非 departId）
│   │       └── includeChildFlg     1=含下级部门
│   │
│   ├── leadHighSea（线索公海池）
│   │   ├── [固定列] 同上
│   │   ├── [业务字段]
│   │   │   ├── assignRule          领取规则
│   │   │   ├── recycleRule         回收规则
│   │   │   ├── transferRule        转移规则
│   │   │   ├── noActivitiesDay     无跟进回收天数
│   │   │   ├── noContactDay        无联系回收天数（线索特有）
│   │   │   ├── remindDay           提前提醒天数
│   │   │   ├── claimLimitDay       回收后禁领天数
│   │   │   ├── releaseLimit        退回次数限制
│   │   │   ├── claimMaxCount       每人最大持有数
│   │   │   ├── enableFlg           是否启用
│   │   │   └── description         描述
│   │   │
│   │   ├── ◆ leadHighSeaMember（子实体：线索公海成员）
│   │   │   ├── leadHighSeaId       → leadHighSea.id
│   │   │   ├── userId              → user.id
│   │   │   ├── memberRole          0=成员 1=管理员 2=默认管理员
│   │   │   └── memberStatus        1=启用 0=停用
│   │   │
│   │   └── ◆ leadHighSeaDepart（子实体：线索公海部门范围）
│   │       ├── leadHighSeaId       → leadHighSea.id
│   │       ├── departApiKey        部门 apiKey
│   │       └── includeChildFlg     1=含下级部门
│   │
│   └── territory（销售区域 — 兼任区域公海）
│       ├── [已有字段] territoryName / parentTerritoryId / status / ...
│       ├── [公海扩展字段]
│       │   ├── accountHighSeaFlg   1=启用客户区域公海
│       │   ├── leadHighSeaFlg      1=启用线索区域公海
│       │   ├── noActivitiesDay     回收天数（共用）
│       │   ├── recycleRule         回收规则（共用）
│       │   ├── remindDay           提前提醒天数
│       │   ├── claimLimitDay       回收后禁领天数
│       │   ├── claimMaxCount       每人最大持有数
│       │   ├── noNewOppDay         无新商机天数（客户特有）
│       │   └── noContactDay        无联系天数（线索特有）
│       │
│       └── [成员] 复用 territory 团队成员（p_data_share），不新增子实体
│
├── 业务数据（记录级别，销售日常操作）
│   │
│   ├── account（客户）
│   │   ├── [公海关联字段]
│   │   │   ├── highSeaId               → highSea.id（所属普通公海）
│   │   │   ├── highSeaStatus           active / inHighSea / claimed
│   │   │   ├── territoryHighSeaId      → territory.id（所属区域公海）
│   │   │   ├── claimTime               领取时间
│   │   │   ├── expireTime              到期时间
│   │   │   └── releaseDescription      退回原因
│   │   │
│   │   └── [业务关联]
│   │       ├── → contact（联系人，1:N）
│   │       ├── → opportunity（商机，1:N）
│   │       └── → order / contract（订单/合同）
│   │
│   ├── lead（线索）
│   │   ├── [公海关联字段]
│   │   │   ├── leadHighSeaId           → leadHighSea.id（所属普通公海）
│   │   │   ├── leadHighSeaStatus       active / inHighSea / claimed / converted / invalid
│   │   │   ├── territoryLeadHighSeaId  → territory.id（所属区域公海）
│   │   │   ├── claimTime               领取时间
│   │   │   ├── expireTime              到期时间
│   │   │   ├── releaseNum              退回次数
│   │   │   └── lastOwnerId             退回前所有人
│   │   │
│   │   └── [转化出口]
│   │       ├── → account（L2O 转化创建客户）
│   │       ├── → contact（L2O 转化创建联系人）
│   │       └── → opportunity（L2O 转化创建商机）
│   │
│   ├── opportunity（商机）
│   │   ├── accountId                   → account.id
│   │   ├── contactId                   → contact.id
│   │   ├── stageName                   商机阶段
│   │   ├── amount                      金额
│   │   └── [影响公海回收]
│   │       ├── 新建商机 → 重置 account 的 noNewOppDay 计时
│   │       └── 赢单 → 重置 account 的 noTransferDay 计时
│   │
│   └── contact（联系人）
│       └── accountId                   → account.id
│
└── 支撑实体
    ├── user（用户）
    ├── department（部门，apiKey 关联）
    └── role（角色）
```

## 二、权限判定树

```
用户请求公海操作（领取/退回/分配/转移/查看）
│
├── 1. 确定公海池
│   │
│   ├── 普通公海 → 从业务数据取 highSeaId / leadHighSeaId
│   └── 区域公海 → 从业务数据取 territoryHighSeaId / territoryLeadHighSeaId
│
├── 2. 判定用户角色（HighSeaPermissionService.resolveRole）
│   │
│   ├── 系统管理员？
│   │   └── DataPermission.canOperateAll(entity, UPDATE) == true
│   │       → 角色 = SYSTEM_ADMIN（最高权限）
│   │
│   ├── 公海管理员？
│   │   ├── [普通公海] 查 highSeaMember / leadHighSeaMember
│   │   │   └── memberRole IN (1, 2) → 角色 = POOL_ADMIN
│   │   └── [区域公海] 查 territory 团队成员
│   │       └── accessLevel = 2 → 角色 = POOL_ADMIN
│   │
│   ├── 公海成员？
│   │   ├── [普通公海] 两条路径（OR）
│   │   │   ├── 路径 A：查 highSeaMember，memberRole = 0 → 角色 = POOL_MEMBER
│   │   │   └── 路径 B：查 highSeaDepart
│   │   │       ├── 用户 departApiKey == 公海池 departApiKey → 角色 = POOL_MEMBER
│   │   │       └── includeChildFlg=1 且用户部门是下级 → 角色 = POOL_MEMBER
│   │   └── [区域公海] 查 territory 团队成员
│   │       └── accessLevel >= 1 → 角色 = POOL_MEMBER
│   │
│   └── 以上都不满足 → 角色 = NONE（无权限）
│
└── 3. 按角色 × 操作 × 配置 判定
    │
    ├── 领取（claim）
    │   ├── NONE → ❌ 403
    │   ├── assignRule = 1（手动分配模式）
    │   │   ├── POOL_MEMBER → ❌ "该公海池为手动分配模式"
    │   │   └── POOL_ADMIN / SYSTEM_ADMIN → ✅（走分配逻辑）
    │   ├── assignRule = 0（自行领取模式）
    │   │   └── POOL_MEMBER / POOL_ADMIN / SYSTEM_ADMIN → 进入限额校验 ↓
    │   │
    │   └── 限额校验链
    │       ├── claimMaxCount > 0 且 持有数 >= claimMaxCount → ❌ "超过持有上限"
    │       ├── claimLimitDay > 0 且 该用户最近退回该数据 < N 天 → ❌ "冷却期内"
    │       ├── releaseLimit > 0 且 该数据退回次数 >= releaseLimit → ❌ "已冻结"
    │       └── 全部通过 → ✅ 执行领取
    │
    ├── 退回（release）
    │   ├── NONE → ❌ 403
    │   ├── POOL_MEMBER → 仅允许退回自己 ownerId 的数据
    │   └── POOL_ADMIN / SYSTEM_ADMIN → 可退回任意数据
    │
    ├── 分配（assign）
    │   ├── NONE / POOL_MEMBER → ❌ 403
    │   └── POOL_ADMIN / SYSTEM_ADMIN → ✅（需校验目标用户限额）
    │
    ├── 转移分组（change）
    │   ├── NONE → ❌ 403
    │   ├── transferRule = 0（仅管理员）
    │   │   ├── POOL_MEMBER → ❌ 403
    │   │   └── POOL_ADMIN / SYSTEM_ADMIN → ✅
    │   └── transferRule = 1（成员可转）
    │       └── POOL_MEMBER / POOL_ADMIN / SYSTEM_ADMIN → ✅
    │
    ├── 查看详情（detail）
    │   ├── NONE → ❌ 403
    │   └── POOL_MEMBER / POOL_ADMIN / SYSTEM_ADMIN → ✅
    │
    ├── 修改团队成员（updateTeamMember）
    │   ├── NONE / POOL_MEMBER → ❌ 403
    │   └── POOL_ADMIN / SYSTEM_ADMIN → ✅
    │
    └── 删除（delete）
        ├── NONE / POOL_MEMBER → ❌ 403
        └── POOL_ADMIN / SYSTEM_ADMIN → ✅
```

## 三、数据流转状态机

### 3.1 客户公海状态流转

```
                         ┌──────────────────────────────────────┐
                         │           新建客户                     │
                         └──────────┬───────────────────────────┘
                                    │
                         ┌──────────▼───────────────────────────┐
                         │  判断：是否配置了公海池？                │
                         └──────┬──────────────────┬────────────┘
                                │ 是                │ 否
                    ┌───────────▼──────┐   ┌───────▼────────┐
                    │  进入公海池        │   │  直接分配销售    │
                    │  status=inHighSea │   │  status=active │
                    └───────┬──────────┘   └────────────────┘
                            │
              ┌─────────────┼─────────────┐
              │ 销售领取      │ 管理员分配    │
              ▼             ▼             │
    ┌─────────────────┐                   │
    │  status=claimed  │◄─────────────────┘
    │  ownerId=销售ID   │
    │  claimTime=now   │
    │  expireTime=计算  │
    └────┬────┬────┬──┘
         │    │    │
         │    │    │ 超时未跟进 / 无新商机 / 无成交
         │    │    ▼
         │    │  ┌─────────────────┐
         │    │  │  自动回收         │
         │    │  │  status=inHighSea│──→ 回到公海池
         │    │  │  ownerId=null   │
         │    │  └─────────────────┘
         │    │
         │    │ 手动退回
         │    ▼
         │  ┌─────────────────┐     releaseNum >= releaseLimit?
         │  │  退回公海         │──→ 是 → ┌──────────┐
         │  │  status=inHighSea│         │ 冻结      │
         │  │  releaseNum += 1 │         │ thawDay后 │
         │  └─────────────────┘         │ 自动解冻   │
         │                              └──────────┘
         │ 转移给其他销售
         ▼
    ┌─────────────────┐
    │  ownerId=新销售   │
    │  claimTime=重置   │
    └─────────────────┘
```

## 四、公海池选择路由

```
业务数据创建/导入
│
├── 1. 区域匹配（优先）
│   │
│   │  按区域规则引擎匹配 territory
│   │
│   ├── 匹配到区域 territory
│   │   │
│   │   ├── territory.accountHighSeaFlg = 1（客户）
│   │   │   └── account.territoryHighSeaId = territory.id
│   │   │       account.highSeaStatus = 'inHighSea'
│   │   │
│   │   ├── territory.leadHighSeaFlg = 1（线索）
│   │   │   └── lead.territoryLeadHighSeaId = territory.id
│   │   │       lead.leadHighSeaStatus = 'inHighSea'
│   │   │
│   │   └── 区域未开启公海
│   │       └── 仅设置 territoryId，不进入公海
│   │
│   └── 未匹配到区域 → 走普通公海 ↓
│
└── 2. 普通公海分配
    │
    ├── 按部门范围匹配公海池
    │   │
    │   │  遍历所有启用的公海池（enableFlg=1）
    │   │  检查 highSeaDepart / leadHighSeaDepart
    │   │  用户 departApiKey 是否在范围内（含 includeChildFlg）
    │   │
    │   ├── 匹配到公海池
    │   │   ├── account.highSeaId = highSea.id
    │   │   │   account.highSeaStatus = 'inHighSea'
    │   │   └── lead.leadHighSeaId = leadHighSea.id
    │   │       lead.leadHighSeaStatus = 'inHighSea'
    │   │
    │   └── 未匹配 → 不进入公海，直接分配给创建人
    │
    └── 手动指定公海池（管理员操作）
        └── putIntoHighSea API
```

## 五、自动回收判定树

```
定时任务（每小时执行）
│
├── 扫描 account（客户公海回收）
│   │
│   │  WHERE highSeaStatus = 'claimed'
│   │    AND expireTime < now
│   │    AND deleteFlg = 0
│   │
│   └── 对每条超时记录
│       │
│       ├── 读取公海池配置（highSea / territory）
│       │
│       ├── 回收条件判定（OR 关系，任一满足即回收）
│       │   ├── noActivitiesDay > 0 且 最近活动距今 > N 天 → 回收
│       │   ├── noNewOppDay > 0 且 客户下无新商机 > N 天 → 回收
│       │   ├── noTransferDay > 0 且 客户下无赢单 > N 天 → 回收
│       │   └── 以上都不满足 → 跳过
│       │
│       └── 执行回收
│           ├── ownerId = null
│           ├── highSeaStatus = 'inHighSea'
│           ├── lastOwnerId = 原 ownerId
│           ├── 清理数据权限 share
│           └── 发送回收通知（如配置了 remindDay）
│
└── 扫描 lead（线索公海回收）
    │
    │  WHERE leadHighSeaStatus = 'claimed'
    │    AND expireTime < now
    │    AND deleteFlg = 0
    │
    └── 回收条件判定
        ├── noActivitiesDay > 0 且 最近活动距今 > N 天 → 回收
        ├── noContactDay > 0 且 无电话/邮件联系 > N 天 → 回收
        └── 以上都不满足 → 跳过
```

## 六、服务层调用关系

```
Controller 层
│
├── EntityDataApiService
│   ├── GET  /{entity}           列表查询
│   ├── GET  /{entity}/{id}      详情查询
│   ├── POST /{entity}           新建
│   ├── PUT  /{entity}/{id}      更新
│   └── DELETE /{entity}/{id}    删除
│
├── HighSeaOperationApiService
│   ├── PUT  /{entity}/{id}/claim      领取
│   ├── PUT  /{entity}/{id}/release    退回
│   ├── PUT  /{entity}/{id}/assign     分配
│   ├── PUT  /{entity}/{id}/transfer   转移
│   └── POST /lead/{id}/convert        L2O 转化
│
Service 层
│
├── HighSeaOperationService（公海操作，已有）
│   ├── claim()      → 调用 HighSeaPermissionService 校验 → 执行领取
│   ├── release()    → 校验 → 执行退回 → 累加 releaseNum → 冻结判定
│   ├── assign()     → 校验（必须管理员）→ 校验目标用户限额 → 执行分配
│   ├── transfer()   → 校验 → 执行转移
│   └── convertLead() → 创建 account + contact + opportunity
│
├── HighSeaPermissionService（公海权限，新增）
│   ├── resolveRole(poolEntity, poolId, userId) → HighSeaRole
│   ├── checkClaimPermission(poolEntity, poolId, userId) → void / throw
│   ├── checkAssignPermission(poolEntity, poolId, userId) → void / throw
│   └── listVisiblePools(poolEntity, userId) → List<Long>
│
├── HighSeaQuotaService（限额校验，新增）
│   ├── checkQuota(entity, userId, highSeaId) → void / throw
│   ├── checkCooldown(entity, dataId, userId) → void / throw
│   └── checkFreeze(entity, dataId) → void / throw
│
├── DataPermissionFilter（数据权限，已有，需扩展）
│   ├── buildCondition()    列表查询权限
│   ├── checkAccess()       单条数据权限
│   └── 【扩展】公海管理员 fallback 判定
│
└── EntityDataService（通用数据 CRUD，已有）
    ├── listPage()
    ├── getById()
    ├── create()
    └── update()
```
