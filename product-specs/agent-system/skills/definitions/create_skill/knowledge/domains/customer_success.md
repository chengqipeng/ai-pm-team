# 客户成功（Customer Success）— 行业知识指南

> 本文件为 create_skill 提供客户成功领域的专业知识，指导生成具备行业深度的客户健康度/续约/流失预测类技能 Prompt。

---

## 一、业务本质与分析目标

客户成功分析的终极目标不是"展示客户状态"，而是回答三个核心问题：
1. **谁会流失？** — 基于多维信号的流失风险预测
2. **为什么会流失？** — 流失根因诊断
3. **怎么挽回/扩展？** — 差异化的干预策略

---

## 二、客户健康度评分模型（5 维）

### 2.1 五维评估框架

| 维度 | 权重 | 核心问题 | 关键指标 |
|:---|:---|:---|:---|
| 产品使用 | 30% | 客户在用吗？用得深吗？ | 登录频次/功能覆盖/使用深度/活跃用户占比 |
| 关系健康 | 25% | 关系稳定吗？满意吗？ | 联系频次/NPS/投诉率/关键人稳定性 |
| 商业健康 | 20% | 会续约吗？会扩展吗？ | 续约意向/扩展信号/付款及时性/合同剩余期限 |
| 支持健康 | 15% | 问题多吗？解决快吗？ | 工单趋势/解决时效/升级频次 |
| 价值实现 | 10% | 客户得到价值了吗？ | KPI 达成度/ROI 验证/成功案例 |

### 2.2 各维度评分标准

#### 产品使用（30%）

```
评分维度（各 25 分，满分 100）：
├── 登录频次：日活/周活趋势
│   25分：DAU/MAU > 60%，且环比增长
│   15分：DAU/MAU 30-60%，稳定
│   8分：DAU/MAU < 30%，或环比下降 >20%
│   0分：近 30 天无登录
├── 功能覆盖度：使用的功能模块数 / 已购功能总数
│   25分：覆盖 > 70%
│   15分：覆盖 40-70%
│   8分：覆盖 < 40%
├── 使用深度：核心功能的使用频次和复杂度
│   25分：使用高级功能（自定义/集成/自动化）
│   15分：使用标准功能
│   8分：仅使用基础功能
└── 活跃用户占比：活跃用户 / 已开通账号
    25分：> 80%
    15分：50-80%
    8分：< 50%
```

#### 关系健康（25%）

```
├── 联系频次：CSM 与客户的互动频率
│   25分：月均 ≥4次，客户主动发起 >30%
│   15分：月均 2-3次
│   8分：月均 <2次
│   0分：超过 30 天无互动
├── NPS/满意度：
│   25分：NPS ≥ 9（推荐者）
│   15分：NPS 7-8（被动者）
│   8分：NPS ≤ 6（贬损者）
├── 投诉率：
│   25分：无投诉
│   15分：有投诉但已解决
│   0分：有未解决投诉或升级投诉
└── 关键人稳定性：
    25分：对接人稳定 >12 月，有多个联系人
    15分：对接人稳定 6-12 月
    8分：近 6 月有对接人变动
    0分：关键对接人离职且无新接口人
```

#### 商业健康（20%）

```
├── 续约意向信号：
│   正面：主动询问续约/提前续约/增加预算
│   中性：正常沟通，无明确信号
│   负面：询问终止条款/要求降价/缩减范围
├── 扩展信号：
│   强信号：新部门使用/增加用户/询问新产品
│   弱信号：使用量接近上限/提出新需求
├── 付款及时性：
│   正常：按时付款
│   关注：延迟 1-15 天
│   预警：延迟 >15 天
└── 合同剩余期限：
    安全：> 6 月
    关注：3-6 月（应启动续约流程）
    紧急：< 3 月（必须已在续约谈判中）
```

## 三、流失风险预测

### 3.1 流失信号体系

| 信号类别 | 具体信号 | 风险权重 | 时间窗口 |
|:---|:---|:---|:---|
| 使用信号 | 登录频次下降 >30% | 高 | 连续 2 周 |
| 使用信号 | 核心功能使用停止 | 极高 | 连续 1 周 |
| 使用信号 | 活跃用户数减少 >20% | 高 | 连续 1 月 |
| 关系信号 | 联系频次下降 >50% | 中 | 连续 1 月 |
| 关系信号 | 关键对接人离职 | 极高 | 即时 |
| 关系信号 | 会议取消/推迟 ≥2次 | 中 | 连续 1 月 |
| 商业信号 | 询问合同终止条款 | 极高 | 即时 |
| 商业信号 | 付款延迟 >15天 | 高 | 即时 |
| 商业信号 | 要求降价/缩减范围 | 高 | 续约谈判期 |
| 竞品信号 | 接触竞品/参加竞品活动 | 极高 | 即时 |
| 竞品信号 | 内部评估替代方案 | 极高 | 即时 |
| 支持信号 | 工单数量激增 >100% | 中 | 连续 2 周 |
| 支持信号 | 升级投诉 | 高 | 即时 |

### 3.2 风险等级判定

```
风险等级 = f(信号数量, 信号权重, 合同剩余期限)

🔴 高风险（立即干预）：
├── 任一"极高"权重信号命中
├── 或 3+ 个"高"权重信号同时命中
├── 或 健康度评分 < 40 且合同剩余 < 6 月
└── 行动：48h 内启动挽回计划，升级到管理层

🟡 中风险（主动关注）：
├── 1-2 个"高"权重信号命中
├── 或 健康度评分 40-60
├── 或 健康度连续 2 月下降
└── 行动：1 周内安排深度沟通，制定干预计划

🟢 低风险（正常维护）：
├── 无高权重信号
├── 健康度评分 > 60 且稳定
└── 行动：按正常节奏维护，关注扩展机会
```

## 四、挽回策略库

### 4.1 按流失原因的差异化策略

| 流失原因 | 挽回策略 | 关键动作 | 最佳时间窗口 | 历史成功率 |
|:---|:---|:---|:---|:---|
| 使用不足 | 价值激活 | 安排培训/指派专属 CSM/推送使用指南/设置里程碑 | 续约前 90 天 | 60-70% |
| 关键人变动 | 关系重建 | 快速建立新关系/高层对接/价值重述/QBR 安排 | 变动后 30 天内 | 40-50% |
| 竞品替代 | 差异化防守 | 差异化价值证明/迁移成本分析/优惠方案/高层介入 | 评估期内 | 30-40% |
| 预算削减 | 灵活方案 | 降级方案/分期付款/ROI 重新论证/延期续约 | 预算确认前 | 50-60% |
| 产品不满 | 问题修复 | 问题修复承诺+时间表/产品路线图沟通/补偿方案 | 投诉后 14 天内 | 55-65% |
| 价值未实现 | 价值证明 | ROI 量化报告/成功案例对标/使用优化建议 | QBR 时 | 45-55% |

### 4.2 挽回计划模板

```
挽回计划结构：
├── 诊断：流失根因是什么？（基于信号分析）
├── 目标：挽回的具体目标（续约/降级续约/延期）
├── 策略：选择哪种挽回策略？
├── 行动：
│   ├── 第 1 周：[具体动作]
│   ├── 第 2-3 周：[具体动作]
│   └── 第 4 周：[评估效果]
├── 资源：需要谁参与？（CSM/销售/产品/高层）
└── 兜底：如果挽回失败，降级方案是什么？
```

## 五、扩展机会识别

### 5.1 扩展时机信号

```
强信号（可主动推动）：
├── 活跃用户接近许可上限（>80%）
├── 新部门/团队开始使用
├── 客户融资/扩张/新业务线
├── NPS ≥ 9 且主动推荐
├── 合同续约前 60 天（捆绑扩展）
└── 年度 QBR 时（战略对齐）

弱信号（需进一步验证）：
├── 询问新功能/新模块
├── 提出定制需求
├── 使用量持续增长
└── 行业/政策变化带来新需求
```

### 5.2 扩展类型与策略

| 扩展类型 | 触发条件 | 策略 | 预期增长 |
|:---|:---|:---|:---|
| Up-sell（升级） | 使用接近上限/需要高级功能 | 展示高版本价值差异 | 30-50% |
| Cross-sell（交叉） | 新部门/新场景需求 | 从已有成功案例切入 | 50-100% |
| 增加用户 | 活跃用户 >80% 许可 | 按使用数据证明需求 | 20-40% |
| 增值服务 | 有定制/培训/咨询需求 | 打包服务方案 | 10-30% |

## 七、Prompt 设计指导

生成客户成功类技能 Prompt 时，必须确保：

1. **不是状态展示**：不能只列出客户的合同信息和使用数据
2. **必须有评分**：健康度五维评分 + 综合等级
3. **必须有预测**：基于信号的流失风险判定（红/黄/绿）
4. **必须有归因**：风险的根本原因是什么（不是表象）
5. **必须有策略**：针对性的挽回/扩展策略（不是通用建议）
6. **必须有时间线**：什么时候做什么，有明确的行动节奏
