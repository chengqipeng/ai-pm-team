# 商机管理（Opportunity Management）— 行业知识指南

> 本文件为 create_skill 提供商机管理领域的专业知识，指导生成具备行业深度的商机分析类技能 Prompt。

---

## 一、业务本质与分析目标

商机分析的终极目标不是"展示商机字段"，而是回答三个核心问题：
1. **能不能赢？** — 基于多维信号的赢率判断
2. **卡在哪里？** — 识别推进障碍和薄弱环节
3. **下一步做什么？** — 具体的推进动作和优先级

---

## 二、MEDDIC 评估框架

### 2.1 六维度评分标准

每个维度独立评分 0-100%，整体赢率为加权综合。

| 维度 | 权重 | 核心问题 | 评分逻辑 |
|:---|:---|:---|:---|
| Metrics | 15% | 客户的量化业务痛点是什么？ | 有明确量化 ROI=80+，仅定性=40-60，未识别=0-20 |
| Economic Buyer | 20% | 经济决策人是否已接触？ | 多次深度接触=80+，已识别未接触=40-60，未识别=0-20 |
| Decision Criteria | 15% | 评估标准是什么？我方匹配度？ | 标准明确且匹配=80+，部分匹配=40-60，不匹配/不清楚=0-20 |
| Decision Process | 15% | 决策流程和时间线清晰吗？ | 完全清晰=80+，部分清晰=40-60，不清晰=0-20 |
| Identify Pain | 15% | 痛点是客户承认的还是我方假设？ | 客户主动表达=80+，引导后承认=40-60，我方假设=0-20 |
| Champion | 20% | 有内部支持者在推动吗？ | 有且有影响力=80+，有但弱=40-60，无=0-20 |

### 2.2 整体赢率计算

```
赢率 = Σ(维度得分 × 权重) × 阶段系数

阶段系数：
├── 初步接触：0.6
├── 需求确认：0.7
├── 方案演示：0.8
├── 商务谈判：0.9
└── 签约阶段：0.95

示例：MEDDIC 加权得分 72%，当前阶段"方案演示"
赢率 = 72% × 0.8 = 57.6%
```

### 2.3 等级判定

```
🟢 良好（≥70%）：推进顺利，保持节奏
🟡 关注（40-69%）：有薄弱环节，需针对性补强
🔴 风险（<40%）：多维度缺失，需重新评估是否继续投入
```

## 三、商机推进策略

### 3.1 阶段转化基准

| 阶段转化 | 行业平均转化率 | 平均停留天数 | 关键动作 |
|:---|:---|:---|:---|
| 初步接触 → 需求确认 | 60-70% | 7-14天 | 首次会议/需求调研/痛点确认 |
| 需求确认 → 方案演示 | 50-60% | 14-21天 | 方案定制/POC 准备/技术对接 |
| 方案演示 → 商务谈判 | 40-50% | 21-30天 | 报价/合同条款/商务条件 |
| 商务谈判 → 签约 | 70-80% | 14-30天 | 审批流程/合同签署/付款 |

**停留时间预警：**
- 正常：≤ 基准天数
- 关注：超过基准 1.5 倍
- 预警：超过基准 2 倍

### 3.2 风险信号识别

| 风险类别 | 具体信号 | 严重程度 | 建议动作 |
|:---|:---|:---|:---|
| 活动断档 | >14天无任何互动 | 🔴 高 | 48h 内联系 Champion 确认状态 |
| 关键人变动 | Champion 离职/调岗 | 🔴 高 | 立即识别新 Champion，高层对接 |
| 需求变更 | 范围扩大/缩小/方向变化 | 🟡 中 | 重新评估方案匹配度和报价 |
| 预算冻结 | 财年调整/组织变动 | 🔴 高 | 确认冻结范围和恢复时间 |
| 竞品介入 | 客户提及竞品/邀请竞品演示 | 🟡 中 | 强化差异化，加速推进节奏 |
| 决策延迟 | 原定时间线推迟 | 🟡 中 | 确认延迟原因，调整策略 |

### 3.3 赢单路径推荐

```
基于相似商机的成功模式匹配：
├── 匹配维度：同行业 + 同规模 + 同阶段 + 相似金额
├── 提取模式：已赢商机在该阶段的关键动作序列
├── 推荐逻辑：
│   1. 找到 3-5 个最相似的已赢商机
│   2. 提取它们在当前阶段的共性动作
│   3. 对比当前商机已完成的动作
│   4. 差距即为推荐的下一步
└── 输出格式：具体动作 + 联系谁 + 什么时候 + 预期效果
```

## 四、竞争分析框架

### 4.1 竞争态势判断

```
竞争态势 = f(竞品数量, 客户偏好, 我方差异化)

├── 优势（可加速）：无竞品或客户明确偏好我方
├── 均势（需差异化）：有竞品但无明显偏好
├── 劣势（需策略）：客户倾向竞品，我方需改变游戏规则
└── 未知（需情报）：不清楚竞品参与情况 → 通过 Champion 获取
```

### 4.2 差异化策略选择

| 竞争场景 | 策略 | 关键动作 |
|:---|:---|:---|
| 我方先入 | 设置壁垒 | 深化需求理解，让评估标准向我方倾斜 |
| 竞品先入 | 改变规则 | 引入竞品无法满足的新维度 |
| 同时进入 | 速度+深度 | 更快响应 + 更深的业务理解 |
| 替换竞品 | 降低风险 | 量化切换收益，提供迁移保障 |

## 五、赢/丢单归因分析

### 5.1 常见赢单因素（按影响力排序）

1. **Champion 强力推动**（35%）— 内部有人替我们说话
2. **痛点量化清晰**（25%）— 客户自己算清了 ROI
3. **决策链覆盖完整**（20%）— EB/TB/User 都认可
4. **方案匹配度高**（15%）— 技术方案精准解决问题
5. **竞品差异化明显**（5%）— 有独特优势

### 5.2 常见丢单因素（按影响力排序）

1. **无 Champion / Champion 无影响力**（30%）
2. **未接触 Economic Buyer**（25%）
3. **痛点不够痛 / 优先级不够高**（20%）
4. **竞品价格优势**（15%）
5. **决策流程不清晰导致失控**（10%）

## 六、行业基准参考

| 指标 | ToB SaaS 基准 | 优秀线 | 预警线 |
|:---|:---|:---|:---|
| 整体赢率 | 20-25% | >35% | <15% |
| 平均销售周期 | 60-90天 | <45天 | >120天 |
| 平均客单价 | 行业相关 | 同比增长 | 同比下降 |
| 阶段转化率（需求→方案） | 50-60% | >70% | <40% |
| 商机推进速度 | 每 2 周推进 1 阶段 | 每周推进 | >1 月无推进 |

## 七、Prompt 设计指导

生成商机分析类技能 Prompt 时，必须确保：

1. **不是字段罗列**：不能只列出商机名称、金额、阶段就结束
2. **必须有评估**：MEDDIC 每个维度给出完成度评分和整体赢率
3. **必须有对比**：与同阶段已赢/已丢商机的特征对比，识别差距
4. **必须有建议**：基于差距给出具体推进动作（联系谁/做什么/什么时候）
5. **必须有风险标注**：识别当前最大的 1-2 个风险信号
6. **必须有数据溯源**：每个判断标注数据来源
