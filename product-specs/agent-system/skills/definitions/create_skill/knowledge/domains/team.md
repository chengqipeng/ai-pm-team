# 团队管理（Sales Management）— 行业知识指南

> 本文件为 create_skill 提供团队管理领域的专业知识，指导生成具备行业深度的团队绩效/辅导/资源分配类技能 Prompt。

---

## 一、业务本质与分析目标

团队管理分析的终极目标不是"展示排名"，而是回答三个核心问题：
1. **谁需要帮助？** — 识别辅导优先级和具体短板
2. **资源分配合理吗？** — 诊断结构性问题
3. **怎么提升团队产出？** — 可落地的管理动作

---

## 二、团队绩效模型（5 维）

### 2.1 五维评估框架

| 维度 | 核心问题 | 关键指标 | 管理动作 |
|:---|:---|:---|:---|
| 目标达成 | 完成得怎么样？ | 完成率/趋势/差距 | 目标调整/资源倾斜 |
| 效率指标 | 效率高不高？ | 人均产出/周期/客单价 | 流程优化/工具赋能 |
| 能力矩阵 | 能力均衡吗？ | 四维能力评估 | 针对性辅导 |
| 资源分配 | 分配合理吗？ | 客户分配/区域覆盖 | 重新分配/补充资源 |
| 辅导优先级 | 该辅导谁？ | ROI 排序 | 辅导计划制定 |

### 2.2 各维度详细评估标准

#### 目标达成

```
评估维度：
├── 绝对达成率：actual / target × 100%
│   🟢 达标：≥ 100%
│   🟡 接近：80-99%
│   🔴 落后：< 80%
├── 趋势分析：近 3 月的达成率变化
│   上升趋势：连续 2 月环比增长 → 正面
│   下降趋势：连续 2 月环比下降 → 预警
│   波动：无明确趋势 → 关注稳定性
├── 差距分析：
│   剩余目标 = target - actual
│   日均需完成 = 剩余目标 / 剩余工作日
│   可行性判断 = 日均需完成 vs 历史日均产出
└── 同比分析：
    vs 去年同期 / vs 团队均值 / vs 个人历史最佳
```

#### 效率指标

| 指标 | 计算方法 | 行业基准 | 优秀线 | 预警线 |
|:---|:---|:---|:---|:---|
| 人均产出 | 赢单金额 / 人数 | 150-250万/年 | >300万 | <100万 |
| 赢单周期 | 平均从创建到赢单的天数 | 60-90天 | <45天 | >120天 |
| 客单价 | 赢单金额 / 赢单数 | 行业相关 | 同比增长 | 同比下降 |
| 活动转化率 | 赢单数 / 活动总数 | 3-5% | >7% | <2% |
| 商机创建率 | 新商机数 / 月 | 5-8个/人 | >10个 | <3个 |

#### 能力矩阵（四维雷达图）

```
销售能力四象限（每维度 0-100 分）：

开拓能力（Hunting）：
├── 新客户获取数
├── 首次会议转化率
├── 线索跟进速度
└── 评分 = 加权综合

推进能力（Advancing）：
├── 阶段转化率
├── 商机推进速度
├── 多线程覆盖度
└── 评分 = 加权综合

关闭能力（Closing）：
├── 赢率
├── 谈判周期
├── 折扣率控制
└── 评分 = 加权综合

维护能力（Farming）：
├── 续约率
├── 扩展率
├── 客户满意度/NPS
└── 评分 = 加权综合

能力等级：
├── 90-100：标杆级，可作为导师
├── 70-89：优秀，稳定产出
├── 50-69：合格，有提升空间
├── 30-49：需辅导，明确改进方向
└── 0-29：需紧急干预
```

## 三、九宫格绩效矩阵

### 3.1 矩阵定义

```
        │ 低绩效（<80%） │ 中绩效（80-100%）│ 高绩效（>100%）
────────┼───────────────┼────────────────┼───────────────
高潜力  │ ⭐ 重点辅导    │ 🚀 加速培养     │ 👑 晋升候选
中潜力  │ 📋 明确改进    │ ✅ 稳定发展     │ 💪 激励保持
低潜力  │ ⚠️ 绩效改进计划│ 🔄 调整岗位     │ 🛡️ 防止倦怠
```

### 3.2 潜力评估维度

```
潜力 = f(学习速度, 能力提升趋势, 态度/意愿)

高潜力信号：
├── 能力评分连续 3 月提升
├── 主动学习新方法/工具
├── 积极接受反馈并改进
├── 能举一反三，不重复犯错
└── 有清晰的职业发展意愿

低潜力信号：
├── 能力评分长期停滞
├── 抗拒改变和新方法
├── 反复出现相同问题
├── 缺乏自驱力
└── 无职业发展意愿
```

### 3.3 各象限管理策略

| 象限 | 管理策略 | 具体动作 | 时间投入 |
|:---|:---|:---|:---|
| 重点辅导 | 高频 1:1 + 陪访 | 每周 1:1，每月 2 次陪访 | 30% 管理时间 |
| 加速培养 | 挑战性任务 + 导师 | 分配大客户/复杂商机 | 20% |
| 晋升候选 | 授权 + 领导力培养 | 带新人/主持会议/跨部门项目 | 10% |
| 明确改进 | 目标分解 + 周跟踪 | 每周检查改进计划执行 | 15% |
| 稳定发展 | 正常管理节奏 | 双周 1:1，季度回顾 | 10% |
| 激励保持 | 认可 + 新挑战 | 公开表彰/新领域探索 | 5% |
| 绩效改进 | PIP + 明确时间线 | 30/60/90 天改进计划 | 10% |

## 四、辅导优先级算法

### 4.1 ROI 排序逻辑

```
辅导 ROI = 预期提升金额 / (辅导难度 × 时间投入)

计算步骤：
1. 识别每人的"最大短板维度"（能力矩阵中最低分的维度）
2. 估算该短板提升到合格线（70分）的预期收入增量
   增量 = (70 - 当前分) / 100 × 该维度对应的历史收入贡献
3. 评估辅导难度（1-5 分）：
   1分：态度好+有基础+只需方法指导
   3分：需要持续跟进+实战演练
   5分：态度问题+基础薄弱+需要大量时间
4. ROI = 预期增量 / (难度 × 预计辅导周数)
5. 按 ROI 降序排列 → 辅导优先级
```

### 4.2 辅导类型匹配

| 短板维度 | 辅导方式 | 具体内容 | 预期见效时间 |
|:---|:---|:---|:---|
| 开拓弱 | 陪访+话术训练 | 每周 1 次陪同拜访，录音复盘 | 4-6 周 |
| 推进弱 | 案例复盘+方法论 | 每周复盘 1 个商机，MEDDIC 训练 | 6-8 周 |
| 关闭弱 | 谈判技巧+高层陪同 | 模拟谈判+实战中高层支持 | 4-6 周 |
| 维护弱 | 流程建设+模板 | QBR 模板/预警机制/续约 SOP | 8-12 周 |

## 五、资源分配合理性评估

### 5.1 评估维度

| 评估维度 | 计算方法 | 健康标准 | 预警标准 |
|:---|:---|:---|:---|
| 客户集中度 | Top 3 客户收入占比 | < 30% | > 50% |
| 区域覆盖 | 有活动的区域 / 总区域 | > 80% | < 60% |
| 大客户分配 | 大客户数 / 销售人数 | 均匀（±20%） | 偏差 > 50% |
| 新老客户比 | 新客户商机 / 总商机 | 30-50% | < 20% 或 > 70% |
| 能力匹配度 | 客户难度 vs 销售能力 | 匹配 | 严重错配 |

### 5.2 常见资源分配问题

```
问题诊断：
├── 大客户过度集中：1-2 人负责 >50% 大客户 → 风险集中
├── 新人无客户：新人 Ramp 期无足够客户练手 → 成长慢
├── 能力错配：初级销售负责复杂大客户 → 丢单率高
├── 区域空白：部分区域无人覆盖 → 市场机会流失
└── 忙闲不均：部分人超负荷，部分人闲置 → 效率低

调整建议：
├── 大客户分散：每人负责大客户不超过总数的 30%
├── 新人培养：分配 B/C 级客户 + 导师陪同 A 级客户
├── 能力匹配：复杂客户配资深销售，标准客户配中级
├── 区域补充：招聘/调配覆盖空白区域
└── 负载均衡：按客户数 × 难度系数均衡分配
```

## 六、行业基准参考

| 指标 | ToB SaaS 基准 | 优秀线 | 预警线 |
|:---|:---|:---|:---|
| 团队目标达成率 | 60-70% | >80% | <50% |

## 七、Prompt 设计指导

生成团队管理类技能 Prompt 时，必须确保：

1. **不是简单排名**：不能只列出"张三第一、李四第二"就结束
2. **必须有多维评估**：目标达成+效率+能力+资源，至少 3 个维度
3. **必须有诊断**：识别结构性问题（能力错配/资源不均/辅导缺失）
4. **必须有优先级**：辅导谁？先辅导什么？预期多久见效？
5. **必须有具体建议**：可执行的管理动作（"每周 1:1 + 陪访 1 次"）
6. **必须区分个人/团队**：个人诊断 vs 团队整体健康度
