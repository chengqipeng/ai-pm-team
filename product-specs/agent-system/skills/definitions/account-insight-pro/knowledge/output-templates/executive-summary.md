# Executive Summary 输出模板（30秒层）

## 适用场景
- 销售经理周一早会快速决策
- VP级别看客户概览
- 移动端快速浏览

## 格式规范

**严格5行以内，结构固定：**

```
**[核心判断：1句话定性]**

📊 [数据1] | [数据2] | [数据3]

⚡ [最紧急行动：WHO + WHAT + WHEN]

置信度：[confirmed/likely/conflicting] | 上次变化：[增量描述或"首次分析"]
```

## 示例

**伊顿是高价值扩张客户，当前有增购窗口但决策链覆盖不足** [likely]

📊 赢率73% | 在跟商机¥150万 | 决策链缺EB

⚡ 本周通过CTO引荐CFO，补齐经济买家关系

置信度：likely（CRM数据充分，外部信号单一来源） | 上次变化：商机金额+30%，新增停滞预警

## 写作原则
1. 核心判断必须是判断（有观点），不是描述（列事实）
2. 3个数据点选最能支撑判断的，不是最容易获取的
3. 行动必须具体到人（角色）+事（动作）+时间，不能是"加强跟进"
4. 置信度是对整体判断的自评，不是对某个数据点的
