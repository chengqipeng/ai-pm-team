🎯 三种形态选型建议
场景推荐形态理由
轻量代码执行（分析/计算/绘图） AgentCore CI 免运维、免镜像、内置 Python/Node 够用、microVM 隔离最强
需要自定义工具链（ffmpeg/latex/特定版本） Agent Runtime 自定义 Dockerfile 可安装任意依赖、root 权限可控
长期会话 + 跨轮数据保持 Agent Runtime + Session Storage EFS 持久化 + 空闲回收自动恢复，天然支持断续式交互
常驻 Agent 服务内嵌沙箱 Agent Runtime 沙箱逻辑在服务 handler 中，无需外部编排；适合多租户长驻 Agent
跑不可信代码（安全优先） AgentCore CI (SANDBOX 模式) 完全断网 + microVM 隔离 + 非 root，攻击面最小
对标腾讯 AGS 全功能平替 CI + 适配层 或 Runtime (Session Storage GA 后) CI 方案成熟度高（已全量验证）；Runtime 方案能力更全但 Session Storage 仍 Preview
