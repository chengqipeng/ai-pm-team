## 三维评测的职责边界

```
┌─────────────────────────────────────────────────────────────────────────────────┐
│                                                                                   │
│  ┌───────────────────────────────────────────────────────────────────────────┐   │
│  │                          Skill 评测（端到端）                               │   │
│  │         验证：完整业务场景从输入到输出的整体正确性                            │   │
│  │         方式：集成测试，真实或半 Mock 环境                                   │   │
│  │         位置：独立于 promptfoo，走现有 EvalRunner 体系                       │   │
│  └───────────────────────────────────────────────────────────────────────────┘   │
│                                                                                   │
│  ┌──────────────────────┐ ┌──────────────────────┐ ┌──────────────────────────┐ │
│  │     Tool 评测         │ │    Memory 评测        │ │      Agent 评测          │ │
│  ├──────────────────────┤ ├──────────────────────┤ ├──────────────────────────┤ │
│  │                      │ │                      │ │                          │ │
│  │ 被测对象:             │ │ 被测对象:             │ │ 被测对象:                 │ │
│  │   单个 Tool 实例      │ │   Memory 子系统       │ │   Agent 推理引擎          │ │
│  │                      │ │                      │ │                          │ │
│  │ 隔离方式:             │ │ 隔离方式:             │ │ 隔离方式:                 │ │
│  │   不经过 Agent        │ │   独立 Memory 实例    │ │   所有 Tool 被 Mock       │ │
│  │   直接调用工具函数    │ │   预置种子数据        │ │   只验证 Agent 决策       │ │
│  │                      │ │                      │ │                          │ │
│  │ 验证目标:             │ │ 验证目标:             │ │ 验证目标:                 │ │
│  │   • 输入→输出正确     │ │   • 写入→检索一致     │ │   • 意图 → 选对工具       │ │
│  │   • 异常处理正确      │ │   • 新信息覆盖旧      │ │   • 用户表述 → 正确参数   │ │
│  │   • 边界值处理        │ │   • 相关性排序合理     │ │   • 多步编排顺序正确      │ │
│  │   • Schema 返回合规   │ │   • 矛盾信息消解      │ │   • 该拒绝时拒绝          │ │
│  │                      │ │                      │ │   • 信息不足时追问        │ │
│  │ 不关心:               │ │ 不关心:               │ │                          │ │
│  │   Agent 是否选对工具  │ │   Agent 如何调用      │ │ 不关心:                   │ │
│  │   参数是否来自 LLM    │ │   工具功能是否正确    │ │   工具执行结果是否正确    │ │
│  │                      │ │                      │ │   记忆内容是否准确        │ │
│  └──────────────────────┘ └──────────────────────┘ └──────────────────────────┘ │
│                                                                                   │
└─────────────────────────────────────────────────────────────────────────────────┘
```

## Agent 评测中 Mock Tools 的工作机制

```
┌─────────────────────────────────────────────────────────────────────────────────┐
│  Agent 评测执行链路                                                               │
│                                                                                   │
│                                                                                   │
│  "帮我取消订单 ORD-001"                                                          │
│         │                                                                        │
│         ▼                                                                        │
│  ┌─────────────────────────────────────────────────┐                             │
│  │            Agent LLM 推理（真实执行）             │                             │
│  │                                                  │                             │
│  │  思考: 用户要取消订单，需要先查订单再执行取消     │                             │
│  │  决策: 调用 query_data(entity=order, id=ORD-001) │                             │
│  └──────────────────────┬──────────────────────────┘                             │
│                         │                                                        │
│                         ▼                                                        │
│  ┌──────────────────────────────────────────────────┐                            │
│  │          Mock Tool Middleware（拦截层）            │                            │
│  │                                                   │                            │
│  │  ① 记录: tool=query_data, args={entity, id}      │  ──→ call_log[]            │
│  │  ② 响应: 按 mock_preset 返回预设数据              │                            │
│  │  ③ 输出: console.log 当前调用信息                 │                            │
│  └──────────────────────┬───────────────────────────┘                            │
│                         │ 返回 mock 结果                                          │
│                         ▼                                                        │
│  ┌─────────────────────────────────────────────────┐                             │
│  │            Agent LLM 继续推理                     │                             │
│  │                                                  │                             │
│  │  收到查询结果 → 决策: 执行取消                    │                             │
│  │  决策: 调用 modify_data(action=update, ...)       │                             │
│  └──────────────────────┬──────────────────────────┘                             │
│                         │                                                        │
│                         ▼                                                        │
│  ┌──────────────────────────────────────────────────┐                            │
│  │          Mock Tool Middleware（再次拦截）          │                            │
│  │                                                   │                            │
│  │  ① 记录: tool=modify_data, args={action, ...}    │  ──→ call_log[]            │
│  │  ② 响应: 返回 {success: true}                    │                            │
│  └──────────────────────┬───────────────────────────┘                            │
│                         │                                                        │
│                         ▼                                                        │
│  ┌─────────────────────────────────────────────────┐                             │
│  │            Agent 生成最终回复                      │                             │
│  └──────────────────────┬──────────────────────────┘                             │
│                         │                                                        │
│                         ▼                                                        │
│  ┌──────────────────────────────────────────────────┐                            │
│  │               评测断言验证                         │                            │
│  │                                                   │                            │
│  │  输入: call_log = [                               │                            │
│  │    {tool: query_data, args: {entity, id}}         │                            │
│  │    {tool: modify_data, args: {action, data}}      │                            │
│  │  ]                                                │                            │
│  │                                                   │                            │
│  │  断言:                                            │                            │
│  │    ✅ 工具选择: query_data → modify_data          │                            │
│  │    ✅ 调用顺序: 先查后改                          │                            │
│  │    ✅ 参数提取: entity=order, id=ORD-001          │                            │
│  │    ✅ 参数填充: action=update, status=cancelled   │                            │
│  └──────────────────────────────────────────────────┘                            │
│                                                                                   │
└─────────────────────────────────────────────────────────────────────────────────┘
```

## Mock Tools 的三种策略

```
┌─────────────────────────────────────────────────────────────────────────────────┐
│                                                                                   │
│  策略 A: capture_only（轻量级）                                                   │
│  ─────────────────────────────                                                   │
│  场景: 只验证 Agent 选了什么工具、传了什么参数                                     │
│  行为: 拦截 → 记录 → 返回统一的 {success: true}                                  │
│  适用: 意图识别测试、参数提取测试                                                 │
│                                                                                   │
│  策略 B: preset_response（标准级）                                                │
│  ─────────────────────────────────                                               │
│  场景: 验证 Agent 对工具返回值的后续处理逻辑                                      │
│  行为: 拦截 → 记录 → 按条件匹配返回预设数据                                      │
│  适用: 多步编排测试（如查到"已发货"后不应执行取消）                                │
│                                                                                   │
│  策略 C: error_simulation（异常级）                                               │
│  ──────────────────────────────────                                              │
│  场景: 验证 Agent 的容错和重试行为                                                │
│  行为: 拦截 → 记录 → 返回错误/超时                                               │
│  适用: 错误恢复测试、降级策略测试                                                 │
│                                                                                   │
└─────────────────────────────────────────────────────────────────────────────────┘
```
