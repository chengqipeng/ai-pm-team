1. 目标场景与联动模式

1.1 典型业务场景

场景对话框行为页面行为
创建客户Agent 在 Chat 中弹出客户表单，用户填写字段页面侧边栏实时预览客户信息卡片
编辑商机用户说"修改金额为 50 万"，Agent 理解后更新表单字段页面商机详情同步刷新金额
审批流用户在对话中点击"提交审批"按钮页面审批列表新增一条待办
智能填单Agent 根据上下文自动预填表单，用户确认或修改页面表格同步显示新记录（草稿态）

1.2 三种联动模式

Mode ① Chat 驱动页面（Agent → 表单 → 页面同步）

Agent 在 Chat 内渲染表单组件 → 用户填写 → Shared State 更新 → 页面组件响应式刷新

Mode ② 页面驱动对话（页面操作 → Agent 继续）

用户在页面表单上修改字段 → userAction 回传 → Agent 接收并继续处理（如校验、自动补全）

Mode ③ 对话式表单填写（Agent 引导 + 多轮对话）

Agent 逐字段引导用户填写 → 每轮对话更新表单状态 → 最终用户确认提交

2.1 核心设计原则

  • Shared State 唯一数据源：表单字段值、校验状态、提交状态全部存在 /form/{form_id}/ 路径下
  • 结构与数据分离：表单 UI 结构（TextField/Select/Button）通过 ACTIVITY_SNAPSHOT 下发；表单数据通过 STATE_SNAPSHOT/DELTA 驱动
  • 双向绑定通过 path：表单组件的 value 属性绑定到 /form/{form_id}/fields/{field_name}，实现读写联动
  • userAction 闭环：用户在表单上的每次操作（输入、选择、提交）都通过 POST /agent/a2ui/event 回传 Agent

# src/a2ui/form_state.py

from dataclasses import dataclass, field
from typing import Any

@dataclass
class FormFieldDef:
    """单个表单字段定义"""
    name: str                    # 字段标识（camelCase）
    label: str                   # 显示名
    type: str                    # text | number | select | date | boolean
    required: bool = False
    placeholder: str = ""
    options: list[dict] | None = None   # select 类型的选项 [{value, label}]
    default: Any = None
    validation: dict | None = None      # {"pattern": "...", "min": 0, "max": 100}

@dataclass
class FormState:
    """表单运行时状态（存入 Shared State）"""
    form_id: str
    title: str
    fields: dict[str, Any]       # field_name → current value
    status: str = "editing"      # editing | validating | submitted | error
    errors: dict[str, str] = field(default_factory=dict)  # field → error msg
    dirty: list[str] = field(default_factory=list)        # 已修改字段

    def to_shared_state(self) -> dict:
        return {
            "formId": self.form_id,
            "title": self.title,
            "fields": dict(self.fields),
            "status": self.status,
            "errors": dict(self.errors),
            "dirty": list(self.dirty),
        }

    def update_field(self, name: str, value: Any) -> None:
        self.fields[name] = value
        if name not in self.dirty:
            self.dirty.append(name)
        # 清除该字段的错误
        self.errors.pop(name, None)

    def validate(self, field_defs: list[FormFieldDef]) -> bool:
        self.errors = {}
        for fd in field_defs:
            val = self.fields.get(fd.name)
            if fd.required and (val is None or val == ""):
                self.errors[fd.name] = f"{fd.label}为必填项"
        self.status = "error" if self.errors else "validating"
        return not self.errors

3.2 FormBuilder — 表单 UI 构建器

# src/a2ui/form_builder.py

from src.a2ui.builder import A2UIBuilder
from src.a2ui.models import Component
from .form_state import FormFieldDef

class FormBuilder:
    """在 A2UIBuilder 基础上封装表单构建能力。

    用法：
        fb = FormBuilder(form_id="customer_create", title="创建客户")
        fb.add_field(FormFieldDef(name="name", label="客户名称", type="text", required=True))
        fb.add_field(FormFieldDef(name="industry", label="行业", type="select",
                                  options=[{"value":"tech","label":"科技"},...]))
        fb.add_submit(label="创建", action="submit_customer_form")
        surface_fn = fb.build_surface_fn()
    """

    def __init__(self, form_id: str, title: str = "") -> None:
        self.form_id = form_id
        self.title = title
        self._fields: list[FormFieldDef] = []
        self._submit_label: str = "提交"
        self._submit_action: str = "submit_form"
        self._cancel_action: str | None = None

    def add_field(self, field_def: FormFieldDef) -> "FormBuilder":
        self._fields.append(field_def)
        return self

    def add_submit(self, label: str = "提交", action: str = "submit_form",
                   cancel_action: str | None = "cancel_form") -> "FormBuilder":
        self._submit_label = label
        self._submit_action = action
        self._cancel_action = cancel_action
        return self

    @property
    def field_defs(self) -> list[FormFieldDef]:
        return list(self._fields)

    def build_surface_fn(self):
        """返回 SurfaceBuilder 回调，供 A2UIRenderHelper.render() 使用"""
        form_id = self.form_id
        title = self.title
        fields = list(self._fields)
        submit_label = self._submit_label
        submit_action = self._submit_action
        cancel_action = self._cancel_action

        def surface_fn(ui: A2UIBuilder, data_path: str) -> None:
            form_path = f"{data_path}"  # → /data/form/{form_id}
            fields_path = f"{form_path}/fields"
            errors_path = f"{form_path}/errors"

            child_ids = []

            # 标题
            if title:
                ui.text("form_title", literal=title, usage_hint="h3")
                child_ids.append("form_title")

            # 逐字段生成组件
            for fd in fields:
                field_id = f"field_{fd.name}"
                error_id = f"error_{fd.name}"

                if fd.type == "select" and fd.options:
                    # Select 组件（用 MultipleChoice 模拟单选）
                    ui.add(Component(
                        id=field_id,
                        type="MultipleChoice",
                        props={
                            "label": {"literalString": fd.label},
                            "value": {"path": f"{fields_path}/{fd.name}"},
                            "options": {"literalArray": fd.options},
                            "required": {"literalBoolean": fd.required},
                            "action": {
                                "name": "field_change",
                                "context": [
                                    {"key": "formId", "value": {"literalString": form_id}},
                                    {"key": "field", "value": {"literalString": fd.name}},
                                ]
                            },
                        }
                    ))
                elif fd.type == "boolean":
                    ui.add(Component(
                        id=field_id,
                        type="CheckBox",
                        props={
                            "label": {"literalString": fd.label},
                            "value": {"path": f"{fields_path}/{fd.name}"},
                            "action": {
                                "name": "field_change",
                                "context": [
                                    {"key": "formId", "value": {"literalString": form_id}},
                                    {"key": "field", "value": {"literalString": fd.name}},
                                ]
                            },
                        }
                    ))
                else:
                    # TextField（text / number / date）
                    props = {
                        "value": {"path": f"{fields_path}/{fd.name}"},
                        "label": {"literalString": fd.label},
                        "action": {
                            "name": "field_change",
                            "context": [
                                {"key": "formId", "value": {"literalString": form_id}},
                                {"key": "field", "value": {"literalString": fd.name}},
                            ]
                        },
                    }
                    if fd.placeholder:
                        props["placeholder"] = {"literalString": fd.placeholder}
                    ui.add(Component(id=field_id, type="TextField", props=props))

                # 错误提示（绑定到 errors path）
                ui.add(Component(
                    id=error_id,
                    type="Text",
                    props={
                        "text": {"path": f"{errors_path}/{fd.name}",
                                 "literalString": ""},
                        "usageHint": "error",
                    }
                ))
                child_ids.extend([field_id, error_id])

            # 按钮行
            btn_children = []
            ui.button("btn_submit", label=submit_label, action=submit_action,
                      context={"formId": {"literalString": form_id}})
            btn_children.append("btn_submit")

            if cancel_action:
                ui.button("btn_cancel", label="取消", action=cancel_action,
                          context={"formId": {"literalString": form_id}})
                btn_children.append("btn_cancel")

            ui.row("btn_row", children=btn_children)
            child_ids.append("btn_row")

            # Root column
            ui.column("root", children=child_ids)

        return surface_fn

    def default_values(self) -> dict[str, Any]:
        """根据字段定义生成默认值 dict"""
        return {fd.name: (fd.default if fd.default is not None else "") for fd in self._fields}

3.3 FormSkill — 表单生命周期管理

# src/skills/form_skill.py

from src.a2ui import A2UIRenderHelper
from src.a2ui.form_builder import FormBuilder
from src.a2ui.form_state import FormState, FormFieldDef
from src.agui.models import AGUIEvent

class FormSkill:
    """管理表单的完整生命周期：初始化 → 字段更新 → 校验 → 提交。

    与 A2UIRenderHelper 配合：
    - 初始化：render() 产出 STATE_SNAPSHOT + ACTIVITY_SNAPSHOT
    - 字段更新：update_data() 产出 STATE_DELTA
    - 提交：validate + submit → STATE_DELTA（状态变更）

    Adapter 在收到 userAction 时调用对应方法。
    """

    def __init__(self, helper: A2UIRenderHelper) -> None:
        self._helper = helper
        self._forms: dict[str, FormState] = {}
        self._builders: dict[str, FormBuilder] = {}

    def init_form(
        self,
        form_id: str,
        title: str,
        field_defs: list[FormFieldDef],
        initial_values: dict | None = None,
        submit_label: str = "提交",
        submit_action: str = "submit_form",
    ) -> list[AGUIEvent]:
        """初始化表单：创建状态 + 渲染 UI。

        返回 AG-UI 事件列表（STATE_SNAPSHOT + ACTIVITY_SNAPSHOT）。
        """
        # 构建表单定义
        fb = FormBuilder(form_id=form_id, title=title)
        for fd in field_defs:
            fb.add_field(fd)
        fb.add_submit(label=submit_label, action=submit_action)
        self._builders[form_id] = fb

        # 初始化表单状态
        defaults = fb.default_values()
        if initial_values:
            defaults.update(initial_values)
        state = FormState(
            form_id=form_id,
            title=title,
            fields=defaults,
        )
        self._forms[form_id] = state

        # 通过 RenderHelper 一步完成：数据 + 结构 + 下发
        render_type = f"form/{form_id}"
        return self._helper.render(
            render_type=render_type,
            data=state.to_shared_state(),
            surface_fn=fb.build_surface_fn(),
            notification_message=f"📝 {title}",
        )

    def on_field_change(self, form_id: str, field_name: str, value) -> list[AGUIEvent]:
        """处理字段变更 → 更新 Shared State。"""
        state = self._forms.get(form_id)
        if state is None:
            return []
        state.update_field(field_name, value)
        render_type = f"form/{form_id}"
        return self._helper.update_data(render_type, state.to_shared_state())

    def on_submit(self, form_id: str) -> list[AGUIEvent]:
        """处理表单提交：校验 → 状态变更。"""
        state = self._forms.get(form_id)
        builder = self._builders.get(form_id)
        if state is None or builder is None:
            return []

        # 校验
        valid = state.validate(builder.field_defs)
        render_type = f"form/{form_id}"

        if not valid:
            return self._helper.update_data(render_type, state.to_shared_state())

        # 校验通过 → 标记提交中
        state.status = "submitted"
        return self._helper.update_data(render_type, state.to_shared_state())

    def get_form_data(self, form_id: str) -> dict | None:
        """获取表单当前数据（供业务逻辑使用）"""
        state = self._forms.get(form_id)
        return dict(state.fields) if state else None

4.3 userAction 回传流程

// 前端 A2UI TextField 组件内部 — 用户输入时触发
function A2UITextField({ node, getValue, sharedState }) {
  const value = getValue(node.props.value);    // 从 Shared State 读取当前值
  const action = node.props.action;            // {name: "field_change", context: [...]}

  const handleChange = debounce((newValue) => {
    // Fire-and-forget 回传给 Agent
    fetch('/agent/a2ui/event', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        threadId: currentThreadId,
        userAction: {
          name: action.name,                    // "field_change"
          surfaceId: currentSurfaceId,
          sourceComponentId: node.id,           // "field_name"
          timestamp: new Date().toISOString(),
          context: {
            formId: resolveContext(action.context, 'formId'),
            field: resolveContext(action.context, 'field'),
            value: newValue,                    // ★ 已 resolve 的实际值
          }
        }
      })
    });
  }, 300);

  return <Input value={value} onChange={e => handleChange(e.target.value)} />;
}

4.4 响应式更新链路

完整链路（字段修改）

  1. 用户在 Chat 内 TextField 输入 "工商银行"
  2. 前端 debounce 300ms 后 POST /agent/a2ui/event（userAction: field_change）
  3. 后端 A2UIInboundHandler → inject_message() → Agent 下次 execute 时消费
  4. Agent 调 FormSkill.on_field_change("customer_create", "name", "工商银行")
  5. 产出 STATE_DELTA: [{op:"replace", path:"/data/form~1customer_create/fields/name", value:"工商银行"}]
  6. 前端 Shared State 更新 → Chat 内 TextField 确认值 + 页面 CustomerPreviewCard 同步刷新

async def _handle_user_action(self, thread_id: str, ua_msg) -> list:
    """解析 userAction HumanMessage，路由到对应 Skill。"""
    import json
    content = ua_msg.content if hasattr(ua_msg, 'content') else str(ua_msg)

    # 解析 [ui-action] 格式
    if not content.startswith("[ui-action]"):
        return []

    # 从 additional_kwargs 提取结构化信息
    kwargs = getattr(ua_msg, 'additional_kwargs', {}) or {}
    ui_action = kwargs.get('ui_action', {})
    action_name = ui_action.get('name', '')
    context = ui_action.get('context', {})

    form_id = context.get('formId', '')

    if action_name == 'field_change':
        field = context.get('field', '')
        value = context.get('value', '')
        return self._form_skill.on_field_change(form_id, field, value)

    elif action_name.startswith('submit_'):
        events = self._form_skill.on_submit(form_id)
        # 提交成功后调用业务逻辑
        if self._form_skill.get_form_data(form_id):
            state = self._form_skill._forms.get(form_id)
            if state and state.status == "submitted":
                # 触发业务逻辑（如调用 CRM API）
                pass
        return events

    elif action_name == 'cancel_form':
        # 取消表单 → 清空状态
        return self._helper.update_data(
            f"form/{form_id}",
            {"formId": form_id, "status": "cancelled", "fields": {}, "errors": {}, "dirty": []}
        )

    return []

class ActionDispatcher:
    def __init__(self, view_service, form_service, agent_adapter, stream_hub):
        self._handlers = {
            "create_record": view_service.open_create_form,
            "view_record": view_service.open_detail,
            "edit_record": view_service.open_update_form,
            "refresh_view": view_service.refresh,
            "change_page": view_service.change_page,
            "change_selection": view_service.change_selection,
            "field_change": form_service.change_field,
            "submit_create": form_service.submit_create,
            "submit_update": form_service.submit_update,
            "delete_record": view_service.delete_record,
        }
        self._agent_adapter = agent_adapter
        self._stream_hub = stream_hub

    async def dispatch(self, thread_id: str, action: UserAction) -> str:
        self._validate_envelope(action)
        handler = self._handlers.get(action.name)

        if handler:
            # 确定性操作：不经过 LLM
            events = await handler(thread_id, action.context)
            await self._stream_hub.publish_many(thread_id, events)
            return "accepted"

        # 语义操作：转换为 HumanMessage 并立即启动新一轮 Agent Run
        message = A2UIInboundHandler.to_human_message(action)
        await self._agent_adapter.start_injected_run(thread_id, message, self._stream_hub)
        return "accepted"

9.5 当前实现缺口：入站事件不会自动继续执行

当前 /agent/a2ui/event 只调用 adapter.inject_message() 放入 pending 队列，必须等下一次 /api/chat/agui 请求才会被消费；因此按钮点击后不能可靠地在“原 SSE”上立即回流。

必须新增：

  • ThreadStreamHub：按 thread_id 维护事件发布/订阅队列，页面和 Chat 共用。
  • ActionDispatcher：收到 userAction 后立即执行确定性 Handler 或启动注入式 Agent Run。
  • GET /api/chat/agui/tail?threadId=... 或改造现有长连接：持续订阅 StreamHub，接收按钮操作后的后续事件。
  • 同一 thread 的业务变更串行化；新动作到来时按策略排队、拒绝或取消旧 Run。

async def dispatch(self, thread_id: str, action: UserAction) -> str:
    normalized = await self._normalize_and_authorize(thread_id, action)

    # hidden 操作不发 Chat Activity，其余操作立即在对话框占位
    if normalized.chat_visibility != "hidden":
        accepted = ui_action_activity(normalized, "accepted", status_text="已接收")
        await self._stream_hub.publish(thread_id, accepted)
        await self._action_writer.create(normalized, accepted)

    try:
        if normalized.chat_visibility != "hidden":
            await self._stream_hub.publish(
                thread_id,
                ui_action_activity(normalized, "running", status_text="正在处理…"),
            )

        events, result = await self._execute(normalized)
        await self._stream_hub.publish_many(thread_id, events)

        if normalized.chat_visibility != "hidden":
            finished = ui_action_activity(
                normalized, "succeeded",
                status_text=result.display_text,
                result=result.to_dict(),
            )
            await self._stream_hub.publish(thread_id, finished)
            await self._action_writer.finish(normalized.action_id, result)
        return "accepted"
    except Exception as exc:
        failed = ui_action_activity(
            normalized, "failed",
            status_text=self._safe_error_text(exc),
            error={"code": self._error_code(exc)},
        )
        await self._stream_hub.publish(thread_id, failed)
        await self._action_writer.fail(normalized.action_id, exc)
        return "accepted"

10. 创建与更新完整流程

10.1 创建记录

  1. 用户在 Chat 输入“创建客户”，或点击表格工具栏“新建”。
  2. create_record Handler 获取实体字段元数据和当前用户权限。
  3. 创建 form_customer_create View State，并同时向 Chat 或真实页面目标 Surface 下发表单结构。
  4. 用户输入触发 field_change，后端执行字段校验并发 STATE_DELTA；页面预览和 Chat 表单同步更新。
  5. 点击提交触发 submit_create，由 RecordActionService 在 agent-system 内完成字段白名单、必填和权限校验。
  6. BusinessRecordDAO 在同一逻辑事务内写入本地 PostgreSQL ai_business_record；Agent、路由和前端不得绕过 Service 直接写库。
  7. 创建成功后以一个逻辑事务顺序更新：表格/列表插入记录 → 打开详情 → 表单标记 submitted → Chat 输出成功消息。

10.2 更新记录

  1. 从表格行、列表卡片、详情页或 Chat 指令触发 edit_record。
  2. 后端重新查询最新记录，创建 mode=update 表单，并记录 expectedVersion。

  5. 成功后将服务端返回的完整最新记录投影到所有关联视图。
  6. 若版本冲突，表单状态设为 conflict，返回差异并让用户选择“重新加载”或“覆盖”（覆盖需额外权限和确认）。

class ViewProjectionService:
    def project_record_updated(self, entity_api_key: str, record: dict) -> list[AGUIEvent]:
        patches = []

        patches += self._replace_detail_records(entity_api_key, record_key, record)

11.4 agent-system 内部业务服务边界

  • 全部业务能力由 agent-system 实现：ActionDispatcher 负责白名单调度，RecordActionService 负责校验和业务规则，BusinessRecordDAO 负责 PostgreSQL 持久化。
  • 自然语言 Agent Tool 与页面 Action Handler 必须共用同一个 PersistentCrmBackend 和 ai_business_record，禁止形成两套业务真值。
  • 前端不存储业务真值，不在 localStorage 或内存中实现业务规则；Shared State 是会话展示态，不替代 agent-system PostgreSQL。
  • 字段白名单、必填、格式、租户隔离、确认和乐观锁必须在 RecordActionService 中校验；路由、Agent 和前端禁止直接调用 DAO。
  • Service 返回持久化后的完整标准记录，再由 ProjectionService 更新 Chat 和页面视图，禁止以前端提交值作为最终真值。

11.5 并发、幂等与事件顺序

  • 幂等：所有变更 Action 必须携带 idempotencyKey；相同 key 返回原执行结果。
  • 串行：同一 thread + entity + record 的变更操作进入串行队列。
  • 乐观锁：更新必须携带 expectedVersion；冲突返回 409 并生成 conflict 状态。
  • 事件顺序：operation_started → business_result → STATE_DELTA → ACTIVITY → TEXT_MESSAGE → operation_finished。
  • 失败回滚：前端可以乐观展示 loading，但业务失败后必须用服务端快照恢复并展示错误。

12.3 MVP 范围
