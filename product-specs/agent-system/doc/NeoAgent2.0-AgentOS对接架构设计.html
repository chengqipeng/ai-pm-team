一、两系统架构对比

NeoAgent2.0（企业级 CRM Agent 系统）

  • 定位：Agent 大脑 — "决定做什么、怎么做"
  • 核心能力：意图推理 / 记忆系统 / 上下文工程 / Agentic RAG / Multi-Agent
  • 协议：AG-UI 事件流 + A2UI 声明式 UI
  • 运行时：自建 K8S + LangGraph Agent Loop
  • 存储：PostgreSQL + Redis + 向量数据库
  • 多租户：RLS 行级隔离 + Namespace

AgentOS / CloudAgent（云端沙箱运行时）

  • 定位：Agent 沙箱 — "保证安全运行、可管理、可恢复"
  • 核心能力：Runtime 管理 / ACP 通信 / Checkpoint / Manifest 注入
  • 协议：ACP（Agent Communication Protocol）+ SSE
  • 运行时：云端容器沙箱（按 Runtime 隔离）
  • 存储：沙箱文件系统 + 快照存储
  • 多租户：Runtime 级容器隔离

2.2 职责边界定义

NeoAgent2.0 负责（不变）：LLM 推理、意图理解、记忆管理、上下文压缩、Skill/Tool 编排、AG-UI/A2UI 事件产生、业务权限控制、资源点计费。
AgentOS 负责（新增依赖）：Runtime 沙箱创建/销毁、容器级隔离、ACP 通信标准化、Checkpoint/Version 快照、Manifest 配置注入、Webhook 事件推送、弹性伸缩。
Bridge 对接层负责（新增开发）：AG-UI ↔ ACP 协议转换、Runtime 生命周期编排、Session 映射与重连、Manifest 配置生成、Webhook 事件消费与路由、状态同步、故障降级。

1:1 独占每个租户一个独立 Runtime企业版客户、数据隔离要求高

            return self._pool[key].runtime_id

5.2 ACPBridge 核心实现

# agentos_bridge/acp_bridge.py

class ACPBridge:
    """AG-UI ↔ ACP 双向协议桥接器"""

    async def stream_bridge(
        self, runtime_id: str, session_id: str, user_input: str
    ) -> AsyncIterator[AGUIEvent]:
        """
        核心桥接：用户输入 → ACP → AgentOS Runtime → ACP响应 → AG-UI事件流
        """
        # 1. 建立/复用 SSE 连接
        acp_stream = await self.client.connect_sse(runtime_id)
        # 2. 通过 ACP 发送用户消息
        await self.client.send_message(runtime_id, session_id, user_input)
        # 3. 消费 ACP 响应流，实时转换为 AG-UI 事件
        async for acp_event in acp_stream:
            for agui_event in self._acp_to_agui(acp_event):
                yield agui_event

    def _acp_to_agui(self, acp_event: ACPEvent) -> list[AGUIEvent]:
        """ACP → AG-UI 事件转换（一对多映射）"""
        match acp_event.type:
            case "content_block_start":
                if acp_event.content_type == "text":
                    return [text_message_start(acp_event.id)]
                elif acp_event.content_type == "tool_use":
                    return [tool_call_start(acp_event.id, acp_event.name)]
            case "content_block_delta":
                if acp_event.delta_type == "text_delta":
                    return [text_message_content(acp_event.id, acp_event.text)]
                elif acp_event.delta_type == "input_json_delta":
                    return [tool_call_args(acp_event.id, acp_event.partial_json)]
            case "content_block_stop":
                return [text_message_end(acp_event.id)]
            case "message_stop":
                return [run_finished(acp_event.run_id, acp_event.thread_id)]
        return []

    async def handle_tool_result(self, runtime_id, session_id, tool_call_id, result):
        """将 NeoAgent Tool 执行结果回传给 AgentOS"""
        await self.client.send_tool_result(runtime_id, session_id, tool_call_id, result)

模式描述适用场景

7.3 断线重连机制

class SessionCoordinator:
    async def reconnect(self, thread_id: str) -> bool:
        """断线重连（指数退避 + 首包重放）"""
        mapping = self._mapping.get(thread_id)
        for attempt in ExponentialBackoff(base=1, max_retries=5):
            try:
                await self.client.connect_sse(mapping.runtime_id)
                await self.client.initialize_acp(mapping.runtime_id, mapping.session_id)
                # AgentOS 重连后按固定顺序下发首包：
                # 1. RUN_STARTED  2. MESSAGES_SNAPSHOT  3. STATE_SNAPSHOT
                # 4. ACTIVITY_SNAPSHOT(每个活跃surface)  5. 恢复增量推送
                mapping.is_active = True
                return True
            except ConnectionError:
                await asyncio.sleep(attempt.delay)
        return False

8.2 CheckpointManager

class CheckpointManager:
    async def auto_snapshot(self, runtime_id: str, trigger: str, metadata: dict = None):
        """根据策略自动创建快照"""
        should_snapshot = (
            trigger == "skill_complete" or
            trigger == "user_save" or
            self._round_counter[runtime_id] % self.config.rounds_interval == 0
        )
        if should_snapshot:
            label = f"{trigger}_{datetime.now().isoformat()}"
            checkpoint = await self.client.create_checkpoint(runtime_id, label=label)
            await self._gc_old_checkpoints(runtime_id)
            return checkpoint

    async def restore(self, runtime_id: str, checkpoint_id: str = None):
        """恢复到指定快照（默认最近一个）"""
        if not checkpoint_id:
            checkpoints = await self.client.list_checkpoints(runtime_id)
            checkpoint_id = checkpoints[-1].id
        await self.client.restore_checkpoint(runtime_id, checkpoint_id)
        await self._notify_state_reload(runtime_id, checkpoint_id)

9.2 Webhook 处理流程

class WebhookHandler:
    def verify_signature(self, payload: bytes, signature: str) -> bool:
        """HMAC-SHA256 签名验证"""
        expected = hmac.new(self.secret.encode(), payload, hashlib.sha256).hexdigest()
        return hmac.compare_digest(f"sha256={expected}", signature)

    async def handle(self, request: Request) -> Response:
        payload = await request.body()
        signature = request.headers.get("X-AgentOS-Signature")
        if not self.verify_signature(payload, signature):
            return Response(status_code=401)
        event = json.loads(payload)
        await self.router.dispatch(event["type"], event["data"])
        return Response(status_code=200)

class EventRouter:
    async def _on_runtime_error(self, data: dict):
        """Runtime 异常 -> 自动恢复"""
        runtime_id = data["runtime_id"]
        if data.get("error_code") == "OOM":
            await checkpoint_manager.restore(runtime_id)
            await runtime_manager.scale_up(runtime_id)
        elif data.get("error_code") == "TIMEOUT":
            await runtime_manager.restart(runtime_id)

    async def _on_agent_tool_call(self, data: dict):
        """Agent 请求调用工具 -> 本地执行并回传"""
        result = await tool_executor.execute(data["tool_name"], data["arguments"])
        await acp_bridge.handle_tool_result(
            data["runtime_id"], data["session_id"], data["tool_call_id"], result
        )

十三、风险与实施路线

13.1 风险评估

风险影响概率应对措施
AgentOS 平台不可用Agent 服务中断低降级到本地模式；多区域部署
ACP 协议版本不兼容通信失败中Bridge 版本协商；保留旧版适配器
Runtime 冷启动延迟首次响应慢高Runtime 预热池；Warm Start 策略
状态同步延迟数据不一致中最终一致性设计；冲突检测与合并
Webhook 丢失事件遗漏低幂等处理 + 定期轮询补偿 + 死信队列
Manifest 配置错误Agent 行为异常中配置校验 + 灰度发布 + 快速回滚
多租户资源争抢性能下降中Runtime 资源配额 + 优先级队列
AgentOS 计费超预期成本失控中用量监控告警 + 自动休眠 + 预算上限
