# 记忆提取提示词验证用例

## 验证方法

将每个用例的"用户发言"分别填入四个 prompt 的 `{user_messages}` / `{conversation}` 字段，
`{existing_profile}` / `{existing_rules}` / `{existing_entities}` 填"（无）"，
`{output_language}` 填 "auto"，
用 doubao 2.0 lite 跑，检查输出是否符合期望。

## 如果验证不通过

记录实际输出，分析是 prompt 规则不够还是模型能力问题：
- 如果多个用例同一类错误 → prompt 规则需要调整
- 如果个别用例偶发错误 → 模型能力限制，靠代码层兜底
