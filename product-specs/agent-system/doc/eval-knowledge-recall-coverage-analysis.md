## 四、执行建议

### 第一步: 获取剩余产品 doc_id 映射

需要查找当前未覆盖的核心产品对应 doc_id，至少覆盖：
- 2088, 2051, 3051CF, 3051SFA, 644, 148, 3144P, 1208C, 3308, 2140, 1199, 1595, 935, 370XA

### 第二步: 分批生成用例

1. 先生成 Level 1 (+20条精确型号) — 最简单，直接查型号+验证doc_id
2. 再生成 Level 2 (+36条意图交叉) — 每域6条，需要查对应doc_id
3. 然后 Level 3 (+60条多问法) — 最复杂，需要针对每篇文档设计多种自然语言
4. 最后 Level 4+5 (+30条边界) — 对比/负例/模糊

### 第三步: 断言强度分级

| 级别 | 断言方式 | 适用场景 |
|------|---------|---------|
| **强断言** | CONTAINS doc_id | 精确型号查询、参数规格查询 |
| **中断言** | CONTAINS 产品名关键词 | 场景描述、口语查询 |
| **弱断言** | NOT_CONTAINS "未找到" | 模糊查询、同义词变体 |
| **反向断言** | CONTAINS "未找到" 或 NOT_CONTAINS doc_id | 负例验证 |
