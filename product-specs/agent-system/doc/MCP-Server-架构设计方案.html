crm-data-mcp — CRM 业务数据服务

src/tools/crm_tools.py · 9 Tools · 已实现
CRM MCP Server 提供对销售云业务数据的完整 CRUD + 聚合分析能力。
通过 CrmSimulatedBackend（内部闭环）或 EntityDataHttpBackend（对接 paas-platform-service）
提供 account（客户）、opportunity（商机）、contact（联系人）、activity（活动）、lead（线索）的数据操作。
另含 ManageMemoryTool / MemoryReadTool 支持 Agent 长期记忆管理。
Backend 路由策略： 启动时通过环境变量决定 Backend 类型。 若配置 METAREPO_API_BASE 则使用 HTTP Backend 对接真实服务（走 JWT 认证 + Eureka 服务发现）， 否则降级为 CrmSimulatedBackend 内存模拟。记忆引擎通过 VikingMemoryEngine 连接腾讯 VDB 向量数据库，可通过 DISABLE_MEMORY=1 关闭。
crm_tools.py → CrmSimulatedBackend / EntityDataHttpBackend → salescloud-ai-service /rest/ai/v1/mcp/tool/*
▼ query_schema 查询业务对象元数据定义（字段结构、关联、选项值）
查询 CRM 系统中业务对象的 Schema 信息。Agent 查询到数据后，需要理解字段含义、类型、选项值时调用。 支持 list_entities / entity / entity_items / entity_links / entity_pick_options 五种查询类型。
参数类型必填说明
query_typestring (enum)✓list_entities | entity | entity_items | entity_links | entity_pick_options
entity_api_keystring△业务对象 api_key（entity/entity_items/entity_links 时必填）
item_api_keystring△字段 api_key（entity_pick_options 时必填）
class QuerySchemaTool(Tool): """查询元数据定义 — 查询业务对象的字段结构、关联关系、选项值等 schema 信息""" async def call(self, input_data, context, on_progress=None): result = await self._backend.query_metadata( input_data["query_type"], entity_api_key=input_data.get("entity_api_key", ""), item_api_key=input_data.get("item_api_key", ""), ) if "error" in result: return ToolResult(content=result["error"], is_error=True) return ToolResult(content=json.dumps(result["data"], ensure_ascii=False, indent=2))
▼ query_data 查询业务数据记录（query / get / count）
CRM 数据查询核心工具。支持按条件查询列表（分页、排序、字段筛选）、按 ID 查单条详情、统计记录数。
内含智能重试：若 record_id 不是 ID 格式自动降级为按名称搜索；搜索 0 条时自动拆词重试。
参数类型必填说明
actionstring (enum)✓query | get | count
entity_api_keystring✓account / opportunity / contact / activity / lead
record_idstring△记录 ID（get 时必填）
filtersobject○过滤条件 {"字段": "值"}

page / page_sizeinteger○分页参数，默认 1/20
order_bystring○排序字段（-前缀降序）
class QueryDataTool(Tool): """查询业务数据 — 最常用的数据访问工具""" async def call(self, input_data, context, on_progress=None): action = input_data["action"] entity = input_data["entity_api_key"] if action == "get": rid = input_data.get("record_id") # 智能识别：非 ID 格式自动降级为名称搜索 is_id_format = ( rid.startswith(("acc_", "opp_", "con_", "act_", "lea_")) or rid.isdigit() or rid.startswith("id_") ) if not is_id_format: result = await self._backend.query_data(entity, {"name__contains": rid}) # ... 智能重试 + 拆词搜索 if action == "query": result = await self._backend.query_data( entity, filters, fields=input_data.get("fields"), page=input_data.get("page") or 1, page_size=input_data.get("page_size") or 20, order_by=input_data.get("order_by"), )

sandbox-mcp — 沙盒执行服务

src/tools/sandbox/*.py · 5 Tools · 高危 · 已实现
沙盒 MCP Server 提供隔离的代码执行环境，支持 Python/JS/Shell 代码运行、文件读写、内容搜索。
通过 Backend 抽象层适配多种执行环境：SSH 远程服务器、腾讯云 Agent Runtime 容器、本地 Docker。
所有写操作限制在 /sandbox/.skills/ 目录下，路径自动规范化防止越权。
⚠️ 高危标记：所有工具均为 is_read_only=False，受审计日志 + 权限中间件保护。
Backend 抽象层架构：
Backend(ABC) → SSHBackend / TencentSandboxBackend / LocalBackend
SSHBackend：ControlMaster 连接复用 + Persistent Shell（cd/export 跨命令生效）+ 输出截断保护（50K字符上限，超出走压缩引擎）
TencentSandboxBackend：E2B SDK + 腾讯云 Agent Runtime API（CreateSandboxTool → code-interpreter 模板）
sandbox/*.py → Backend(ABC) → SSHBackend (ControlMaster) / TencentSandboxBackend (E2B SDK)
▼ execute_code 在沙盒中执行代码片段（Python / JS / Shell）
代码写入 Skill 专属 tmp 目录的临时文件后执行，执行完自动清理。
Skill 上下文感知：有 Skill → /sandbox/.skills/{skill_name}/tmp，无 Skill → /sandbox/.skills/.global/tmp。
参数类型必填说明
languagestring (enum)✓python | python3 | javascript | js | node | sh
codestring✓要执行的代码
timeoutinteger○超时秒数（默认 60）
class CodeExecutionTool(Tool): """代码执行 — 在远程沙盒中运行代码片段""" LANGUAGE_RUNNERS = {"python": "python3", "javascript": "node", "sh": "sh"} async def call(self, input_data, context, on_progress=None): tmp_dir = self._resolve_tmp_dir() # Skill 上下文感知 tmp_file = f"{tmp_dir}/exec_{uuid.uuid4().hex[:12]}{ext}" try: await self._backend.execute(f"mkdir -p {tmp_dir}") await self._backend.write_file(tmp_file, code) result = await self._backend.execute(f"{runner} {tmp_file}", timeout=timeout) finally: await self._backend.execute(f"rm -f {tmp_file}") # 自动清理
