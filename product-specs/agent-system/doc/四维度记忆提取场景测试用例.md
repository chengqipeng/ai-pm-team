# 四维度记忆提取场景测试用例（200条）

> 四路并行提取：Profile / Preferences / Agent Rules / Entities
> 覆盖：正例、负例、混合意图、边界对抗、省略主语、口语化、更新/撤销

---

## 设计原则

1. **场景真实**：模拟 CRM 销售场景中的真实对话
2. **覆盖过拟合盲区**：省略主语、口语化、反问、条件句、否定句、多意图混合
3. **边界对抗**：专门设计在两个维度之间摇摆的模糊用例
4. **分布均衡**：四维度正例 + 不提取 + 混合 + 边界对抗

## 场景分布

| 类别 | 数量 | 说明 |

## 反思验证评判标准

### 触发准确率

| 指标 | 定义 | 目标 |
|------|------|------|
| 纠正检测率 | 用户纠正行为被正确识别的比例 | ≥ 95% |
| 冲突检测率 | 语义矛盾被正确检测的比例 | ≥ 90% |
| 误触发率 | 非纠正/非冲突被错误触发反思的比例 | ≤ 5% |

### 解决策略准确率

| 指标 | 定义 | 目标 |
|------|------|------|
| update_old 准确率 | 应更新旧记忆时正确选择 update_old | ≥ 90% |
| archive_old 准确率 | 应归档时正确选择 archive_old | ≥ 85% |
| keep_both 准确率 | 应保留两者时正确选择 keep_both | ≥ 80% |
| discard_new 准确率 | 应丢弃新记忆时正确选择 discard_new | ≥ 80% |

### 修正质量

| 指标 | 定义 | 目标 |
|------|------|------|
| 修正后内容准确率 | 更新后的记忆内容正确反映最新信息 | ≥ 95% |
| 跨维度一致性 | 修正后不引入新的跨维度矛盾 | ≥ 90% |
| 碎片合并完整性 | 合并后的记忆保留所有关键信息 | ≥ 90% |

## 反思触发信号速查

| 触发类型 | 信号词/条件 | 动作 |
|---------|-----------|------|
| 用户纠正 | "不对"、"错了"、"不是这样"、"我改主意了"、"之前说的不算"、"更正一下"、"其实是" | 搜索相关记忆→LLM判断→更新/归档 |
| 冲突检测 | 新记忆与已有记忆 cosine > 0.7 且 LLM 判定为 contradiction/evolution | 4种解决策略选择 |
| 会话结束 | 每次会话 commit 后自动触发 | 新记忆 vs 全库一致性检查 |
| 失败驱动 | Agent 任务执行失败/用户明确否定结果 | 分析召回记忆→降低置信度→新增教训 |
| 全局审计 | 每周定时触发 | 碎片合并+一致性检查+过时标记 |
