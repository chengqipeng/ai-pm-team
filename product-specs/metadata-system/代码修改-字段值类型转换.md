# 代码修改：字段值类型转换（P0 紧急修复）

> 日期：2026-04-28
> 问题：`dbc_bigint27` is of type bigint but expression is of type character varying
> 根因：`EntityDataService` 构建 UpdateWrapper 时，前端传来的值是 String，直接 set 到 BIGINT 列
> 修复：在写入链路加防御性类型转换，根据 dbColumn 前缀强制转换值类型

## 1. 新增 ColumnValueCaster.java

路径：`framework-dao/src/main/java/com/hongyang/framework/dao/util/ColumnValueCaster.java`

```java
package com.hongyang.framework.dao.util;

import lombok.extern.slf4j.Slf4j;
import java.math.BigDecimal;

/**
 * 根据 dbColumn 前缀将字段值转换为正确的 Java 类型。
 *
 * PostgreSQL 不做隐式类型转换，MyBatis-Plus 的 UpdateWrapper.set(column, value)
 * 会直接将 value 的 Java 类型映射到 JDBC 参数类型。如果 value 是 String 但列是 BIGINT，
 * PG 会报 "column is of type bigint but expression is of type character varying"。
 *
 * 本工具类在写入前根据 dbColumn 前缀强制转换，确保 Java 类型与 PG 列类型匹配。
 */
@Slf4j
public final class ColumnValueCaster {

    private ColumnValueCaster() {}

    /**
     * 根据 dbColumn 前缀将值转换为正确的 Java 类型。
     *
     * @param dbColumn 数据库列名，如 "dbc_bigint27", "dbc_varchar3"
     * @param value    前端传入的原始值（可能是 String、Number、Boolean 等）
     * @return 转换后的值，类型与 PG 列类型匹配
     */
    public static Object cast(String dbColumn, Object value) {
        if (value == null || dbColumn == null) {
            return value;
        }

        // 空字符串统一转 null（避免空串写入数字列报错）
        if (value instanceof String && ((String) value).trim().isEmpty()) {
            return null;
        }

        try {
            if (dbColumn.startsWith("dbc_bigint")) {
                return toBigint(value);
            }
            if (dbColumn.startsWith("dbc_decimal")) {
                return toDecimal(value);
            }
            if (dbColumn.startsWith("dbc_smallint")) {
                return toSmallint(value);
            }
            // dbc_varchar, dbc_textarea → String，确保不是非字符串类型
            if (dbColumn.startsWith("dbc_varchar") || dbColumn.startsWith("dbc_textarea")) {
                return toString(value);
            }
            // dbc_array → 保持原值（List<String>）
        } catch (Exception e) {
            log.warn("字段值类型转换失败: dbColumn={}, value={}, type={}, error={}",
                    dbColumn, value, value.getClass().getSimpleName(), e.getMessage());
            return null;
        }

        return value;
    }

    private static Long toBigint(Object value) {
        if (value instanceof Number) {
            return ((Number) value).longValue();
        }
        if (value instanceof String) {
            String s = ((String) value).trim();
            // 处理小数字符串（如 "1001.0"）
            if (s.contains(".")) {
                return new BigDecimal(s).longValue();
            }
            return Long.parseLong(s);
        }
        if (value instanceof Boolean) {
            return ((Boolean) value) ? 1L : 0L;
        }
        return Long.parseLong(value.toString().trim());
    }

    private static BigDecimal toDecimal(Object value) {
        if (value instanceof BigDecimal) {
            return (BigDecimal) value;
        }
        if (value instanceof Number) {
            return BigDecimal.valueOf(((Number) value).doubleValue());
        }
        if (value instanceof String) {
            return new BigDecimal(((String) value).trim());
        }
        return new BigDecimal(value.toString().trim());
    }

    private static Integer toSmallint(Object value) {
        if (value instanceof Number) {
            return ((Number) value).intValue();
        }
        if (value instanceof Boolean) {
            return ((Boolean) value) ? 1 : 0;
        }
        if (value instanceof String) {
            String s = ((String) value).trim().toLowerCase();
            if ("true".equals(s) || "yes".equals(s)) return 1;
            if ("false".equals(s) || "no".equals(s)) return 0;
            return Integer.parseInt(s);
        }
        return Integer.parseInt(value.toString().trim());
    }

    private static String toString(Object value) {
        if (value instanceof String) {
            return (String) value;
        }
        // Number、Boolean 等非字符串类型转为字符串
        return value.toString();
    }
}
```

## 2. 修改 EntityDataService.java

在 `update()` 和 `create()` 方法中，遍历字段值 Map 时调用 `ColumnValueCaster.cast()`。

根据堆栈，写入链路是：
```
EntityDataApiService.updateData()
  → EntityDataService.update()        ← 这里构建字段值 Map
    → TenantDataServiceImpl.update()  ← 这里构建 UpdateWrapper
      → DataBaseServiceImpl.update()
        → AutoTenantDataMapper.update → SQL
```

有两个可选的注入点：

### 方案 A：在 EntityDataService 中转换（推荐）

在 `EntityDataService.update()` 构建字段值 Map 之后、传给 `TenantDataServiceImpl` 之前，对每个 dbc 字段值做类型转换：

```java
// EntityDataService.java — update() 方法中

// 现有代码：构建 dbc 字段值 Map
Map<String, Object> dbcValues = new HashMap<>();
for (XEntityItem item : items) {
    String apiKey = item.getApiKey();
    if (inputData.containsKey(apiKey)) {
        String dbColumn = item.getDbColumn();
        Object value = inputData.get(apiKey);
        // ★★★ 新增：根据 dbColumn 前缀转换值类型 ★★★
        value = ColumnValueCaster.cast(dbColumn, value);
        dbcValues.put(dbColumn, value);
    }
}
```

### 方案 B：在 TenantDataServiceImpl 中转换（兜底）

如果 EntityDataService 中不方便改（比如有多个调用入口），可以在更底层的 `TenantDataServiceImpl.update()` 中做：

```java
// TenantDataServiceImpl.java — update() 方法中

// 现有代码：构建 UpdateWrapper
UpdateWrapper<TenantData> wrapper = new UpdateWrapper<>();
for (Map.Entry<String, Object> entry : dbcValues.entrySet()) {
    String column = entry.getKey();
    Object value = entry.getValue();
    // ★★★ 新增：根据列名前缀转换值类型 ★★★
    value = ColumnValueCaster.cast(column, value);
    wrapper.set(column, value);
}
```

### 方案 C：在 DataBaseServiceImpl 中转换（最底层兜底）

如果要确保所有走 `DataBaseServiceImpl` 的写入都被覆盖：

```java
// DataBaseServiceImpl.java — 覆盖 update 方法

@Override
public boolean update(Wrapper<T> updateWrapper) {
    // 如果是 UpdateWrapper，遍历 SET 子句做类型转换
    // 但 MyBatis-Plus 的 UpdateWrapper 内部结构不方便遍历
    // 所以推荐方案 A 或 B
    return super.update(updateWrapper);
}
```

**推荐方案 A**，在 EntityDataService 中转换，因为这里有完整的元数据上下文（知道每个字段的 dbColumn）。

## 3. 同样需要修改 create 链路

`EntityDataService.create()` 也有同样的问题，构建 INSERT 的字段值时也需要转换：

```java
// EntityDataService.java — create() 方法中

// 构建 TenantData 实体的 dbc 字段值
for (XEntityItem item : items) {
    String apiKey = item.getApiKey();
    if (inputData.containsKey(apiKey)) {
        String dbColumn = item.getDbColumn();
        Object value = inputData.get(apiKey);
        // ★★★ 新增：根据 dbColumn 前缀转换值类型 ★★★
        value = ColumnValueCaster.cast(dbColumn, value);
        setEntityField(entity, dbColumn, value);
    }
}
```
