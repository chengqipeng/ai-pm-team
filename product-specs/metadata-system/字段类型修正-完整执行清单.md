## 阶段 0：防御性代码修复（最高优先级）

不依赖任何元数据修正，在写入链路根据 dbColumn 前缀强制转换值类型：

```java
private Object castToColumnType(String dbColumn, Object value) {
    if (value == null) return null;
    String str = value.toString().trim();
    if (str.isEmpty()) return null;
    try {
        if (dbColumn.startsWith("dbc_bigint"))    return Long.parseLong(str);
        if (dbColumn.startsWith("dbc_decimal"))   return new BigDecimal(str);
        if (dbColumn.startsWith("dbc_smallint"))  return Integer.parseInt(str);
    } catch (NumberFormatException e) {
        log.warn("字段值类型转换失败: dbColumn={}, value={}", dbColumn, value);
        return null;
    }
    return value; // dbc_varchar, dbc_textarea, dbc_array 保持原值
}
```

在 `DataBaseServiceImpl.update()` 和 `insert()` 构建 UpdateWrapper/InsertWrapper 时调用：
```java
wrapper.set(dbColumn, castToColumnType(dbColumn, fieldValue));
```

**此修复上线后，所有 A 类（16 个必炸字段）立即止血，不再报 PSQLException。**
